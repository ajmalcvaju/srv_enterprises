## 🚀 Technology Stack

- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS (Custom `#071C35` Deep Navy, `#1265A8` Royal Blue, `#36C6D9` Aqua Blue palette)
- **Icons:** `lucide-react`
- **Animations:** CSS keyframes + Tailwind transitions
- **SEO:** Dynamic XML Sitemap (`/sitemap.xml`), Robots configuration (`/robots.txt`), Open Graph tags, and Schema.org `LocalBusiness` JSON-LD

## 📄 Pages Included

1. **Home (`/`)**: 5-Slide animated hero carousel, animated count-up statistics, primary categories (Water Purifiers & WTP), troubleshooter, services preview, customer reviews, official notice document showcase, and quote modal.

5. **Contact (`/contact`)**: Contact details, working hours, interactive form with ticket generation, WhatsApp escalation, and embedded Google Maps for Sultan Bathery.

## 🛠️ Local Development & Build

```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev
# Open http://localhost:3000

# 3. Create production build
npm run build

# 4. Start production server
npm run start
```

## 🌐 Deployment on Vercel

1. Push this repository to GitHub, GitLab, or Bitbucket:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of SRV Enterprises corporate website"
   ```
2. Import the project into **Vercel** ([https://vercel.com](https://vercel.com)).
3. Vercel automatically detects Next.js. Click **Deploy**.
